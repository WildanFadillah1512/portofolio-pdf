FITUR UTAMA

Menggabungkan teknologi web modern untuk menghadirkan fitur aksesibilitas suara, proyeksi visual AR, dan penyimpanan data terintegrasi.

+Audio Interaktif (Text-to-Speech)

Memanfaatkan Web Speech API sebagai pemandu suara berbahasa Indonesia saat pengguna mengeksplorasi data planet maupun mengerjakan kuis.

+Visualisasi Markerless WebAR

Menghadirkan objek 3D ke ruang nyata melalui akses kamera perangkat untuk mengamati detail planet dari dekat.

+Sinkronisasi Skor Cloud

Manajemen state dengan Pinia dan basis data SheetDB untuk menyimpan serta menampilkan papan peringkat pemain secara online.
